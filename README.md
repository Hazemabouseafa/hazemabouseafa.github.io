## طريقة التشغيل والمعاينة المحلية

المشروع مصمم بكود نقي (Pure HTML5 / Modern CSS / Vanilla JS) بدون أية اعتمادات ثقيلة، ويمكن تشغيله مباشرة بأي من الطرق التالية:

### الطريقة الأولى: عبر Node.js
```bash
npm start
# أو
node server.js
```
ثم فتح المتصفح على: `http://localhost:3000`

### الطريقة الثانية: فتح مباشر
يمكنك فتح ملف `index.html` في أي متصفح (Chrome, Edge, Safari, Firefox) بنقرة مزدوجة مباشرة.
